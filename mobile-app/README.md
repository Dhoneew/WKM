# WKM Mobile — Wong Kito Mobile

Aplikasi mobile untuk membantu pelanggan Warkop Wong Kito memesan makanan dan minuman dengan lebih mudah melalui smartphone.

## Fitur

- **Onboarding:** Memperkenalkan aplikasi kepada pengguna melalui tiga halaman.
- **Informasi Pemesanan:** Menjelaskan kemudahan pemesanan, proses tanpa antre, dan pemantauan pesanan.

> Catatan: Fitur yang tercantum di atas merupakan fitur yang sudah ditampilkan pada halaman onboarding. Fitur pemesanan sebenarnya akan didokumentasikan setelah implementasinya selesai.

## Teknologi

- Flutter
- Dart
- Material Design

## Persyaratan

Pastikan perangkat pengembangan sudah memiliki:

- Flutter SDK
- Dart SDK (termasuk dalam Flutter SDK)
- Android Studio atau perangkat Android untuk menjalankan aplikasi
- Visual Studio Code (opsional)

## Cara Menjalankan Aplikasi

1. Clone repository:

   ```bash
   git clone https://github.com/Dhoneew/WKM.git
   ```

2. Masuk ke folder aplikasi:

   ```bash
   cd WKM/mobile-app
   ```

3. Unduh dependency:

   ```bash
   flutter pub get
   ```

4. Jalankan aplikasi pada emulator atau perangkat yang terhubung:

   ```bash
   flutter run
   ```
